SW cleanup — drag to bookmarks

If dragging doesn't work, create the bookmark manually

  1. Open the bookmarks bar (Ctrl+Shift+B) and choose "Add page" or right-click > "Add bookmark".
  2. Give it a name like "Unregister SW".
  3. Copy the code from the box below and paste it into the URL/location field of the new bookmark.
  4. Save the bookmark, visit the problematic site and click the bookmark.

Tip: if the browser blocks pasting into the URL field, create the bookmark with any URL, save it, then edit the bookmark and replace the URL with the code above.

Usage: open the site where you see the issue, then click the bookmark you just saved. After the alert, close all tabs for that site and open a single Incognito tab to verify the page loads cleanly.
