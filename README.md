# DocenteDoc AI

**L’assistente intelligente per insegnanti italiani**

DocenteDoc AI è uno strumento **semplice e sicuro** che aiuta gli insegnanti a preparare lezioni, gestire la classe, valutare gli studenti e avere idee in tempo reale — tutto **senza mandare i dati degli studenti su server esterni**.

---

## Per chi è fatto

- Insegnanti della scuola secondaria (medie e superiori)
- Chi vuole usare l’intelligenza artificiale **senza complicazioni**
- Chi tiene alla **privacy** dei propri studenti
- Chi vuole un’app moderna ma **facile da usare**

**Non serve essere informatici.**  
Basta cliccare sui pulsanti “Chiedi all’AI” che trovi ovunque.

---

## Novità recenti (luglio 2026)

Abbiamo reso l’app ancora più semplice e piacevole da usare:

- **Menu laterale semplificato** — Ora c’è una sola sezione chiamata **“Strumenti”** con solo 5 voci (Studenti, Registro, Lezioni, Impostazioni). Molto più pulito e meno confusionario.
- **Pulsante Indietro** — Nell’header in alto appare la freccia ← quando serve. Puoi tornare indietro in modo affidabile.
- **Copilot modernizzato** — La sezione Copilot usa ora un’interfaccia pulita e coerente.
- **Documentazione per insegnanti** — README, guida e pagine GitHub riscritte in italiano semplice.

## Cosa può fare per te (in parole semplici)

| Cosa vuoi fare                        | Come ti aiuta DocenteDoc AI                              |
|---------------------------------------|----------------------------------------------------------|
| Preparare una lezione                 | Ti propone attività, materiali, domande e verifiche      |
| Capire come sta la classe             | Ti mostra grafici semplici e suggerimenti                |
| Valutare compiti o prove              | Ti dà idee di feedback personalizzati                    |
| Rispondere a una domanda in classe    | Ti dà la risposta giusta nel contesto della tua classe   |
| Gestire presenze e note               | Ti aiuta a segnare tutto in modo veloce                  |
| Pianificare una UDA o un percorso     | Ti aiuta a strutturare il lavoro                         |

Tutto funziona anche **senza internet** (tranne quando usi l’AI avanzata).

---

## Le 5 sezioni principali (molto semplici)

1. **Oggi** — La tua pagina iniziale con suggerimenti rapidi
2. **Aula** — Registro, studenti, valutazioni
3. **Pianifica** — Lezioni, UDA, rubriche
4. **Analisi** — Grafici e insight sulla classe
5. **Assistente** — La chat intelligente dedicata

---

## Come si usa (3 passi)

1. Apri l’app
2. Inserisci il tuo nome e la classe (una sola volta)
3. Inizia a usare i pulsanti **“Chiedi all’AI”** che trovi in ogni sezione

Più contesto gli dai (classe, materia, studente), più è preciso.

---

## La privacy è importante

- Per default **tutto resta solo sul tuo computer**
- Puoi decidere tu se sincronizzare con Google Drive (opzionale)
- Non mandiamo i dati degli studenti da nessuna parte senza il tuo consenso

---

## Domande frequenti (per insegnanti)

**Serve essere bravi con il computer?**  
No. È fatta per essere usata come un’app normale.

**Funziona sul telefono?**  
Sì, si adatta bene a telefono, tablet e computer.

**Posso usarla anche senza internet?**  
Sì, la maggior parte delle funzioni funziona offline.

**I dati dei miei studenti sono al sicuro?**  
Sì. Per impostazione predefinita restano solo sul tuo dispositivo.

**È gratis?**  
L’app è gratuita. Per usare l’AI più potente potrebbe servire una chiave (opzionale).

## Vuoi provarla?

1. Clona il repository:
   ```bash
   git clone https://github.com/antoniocorsano-boop/docentedocai.git
   cd docentedocai
   npm install
   npm run dev
   ```

2. Apri nel browser: **http://localhost:5173**

Una volta aperta, basta cliccare sui pulsanti con l’icona dell’AI.
