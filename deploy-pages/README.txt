DOCENTEDOC AI - Teacher Landing Page

Ready to deploy for free:

=== EASIEST: Netlify Drop ===
1. Go to: https://app.netlify.com/drop
2. Drag the entire "deploy-pages" folder (or just index.html) onto the page
3. Done! You'll get a free URL like https://amazing-unicorn-123.netlify.app

=== Alternative: Surge.sh (command line) ===
1. Install: npm install -g surge
2. cd deploy-pages
3. surge
4. Choose a subdomain like docentedocai.surge.sh (free)

=== Alternative: GitHub Pages (web upload, no CLI) ===
1. Go to your repo: https://github.com/antoniocorsano-boop/docentedocai
2. Click "Add file" > "Upload files"
3. Drag the files from deploy-pages into the upload area
4. Commit directly to main branch
5. Then go to Settings > Pages > Source: GitHub Actions (or Deploy from branch "main" /docs)

Your page will be at: https://antoniocorsano-boop.github.io/docentedocai/

This folder contains a clean, standalone version of the landing page.
